# 🎮 Telegram Game Boat Bot 🚢

A feature-rich Telegram bot with 8 exciting games:

1. ⭕ Tic Tac Toe - Classic X and O game
2. 🔢 Guess Number - Find the secret number
3. 🔠 Word Scramble - Unscramble the word
4. ❓ Trivia Quiz - Test your knowledge
5. 💀 Hangman - Guess the word letter by letter
6. 🧠 Memory Match - Find matching pairs
7. 🪨📄✂️ Rock Paper Scissors - Classic hand game
8. 🧮 Math Challenge - Solve math problems fast

## ✨ Features

- Interactive inline buttons
- Real-time multiplayer support
- Leaderboard tracking
- Simple and intuitive interface
- Responsive design

## 🚀 Deployment

### Heroku (One-Click Deploy)
[![Deploy](https://www.herokucdn.com/deploy/button.svg)](https://heroku.com/deploy)

1. Click the button above
2. Set `TOKEN` in Config Vars (get from @BotFather)
3. Deploy!

### Manual Setup
```bash
git clone https://github.com/yourusername/telegram-game-bot.git
cd telegram-game-bot
pip install -r requirements.txt
export TOKEN="your_bot_token"
python bot.py
